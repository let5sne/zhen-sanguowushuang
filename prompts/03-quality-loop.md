## 1. 视觉目标（必须达到的画质基准）

参照 **《对马岛之魂》/《真·三国无双：起源》** 的写实方向（不是"氛围感"）。当前已达成，新增内容**不得回退**：

- **渲染路径**：`WebGLRenderer`（HalfFloat 目标）→ `EffectComposer`
- **Pass 链（5 个，顺序固定）**：
  `RenderPass` → 自写 `BattlefieldAtmosphere`（SSAO + 高度雾 + 体积光，半分辨率，复用 depthTexture）
  → `UnrealBloomPass` → 自写 Grade（ACES + 曝光 1.06 + 对比 1.09 + 饱和 + 暖调 + 暗角 + 暗部抬升）
  → `FXAA`（**必需**：场景渲进 RenderTarget，`renderer antialias` 不生效）
- **灯光**：1 主方向光（2048² 阴影，近端 1024² 跟随）+ 半球环境光 + 轮廓补光；低配预设下阴影降 1024²
- **材质**：全部 `MeshStandardMaterial`，albedo + normal + roughness + metalness 四通道；**禁止纯色 Lambert/Phong 平面**
- **抗锯齿**：FXAA 已启用；实测硬边像素（梯度 >60）0.533% → 0.154%
- **低配预设**：`?low=1` 或按 GPU 字符串自动开启（画质下限 0.45、体积光关、SSAO 4 采样、阴影 1024）

## 2. 资产管线（本项目特化）

**没有 Meshy/Tripo MCP，资产链路是：**

```
scripts/blender/build_geometry.py   → 关楼/营帐/山/道具
scripts/blender/build_rig.py        → 5 套骨骼（hero/dao/spear/archer/officer）+ 10 动画
        ↓ 导出 base64
   内嵌进 demos/index.html 的 SKIN_B64 / 几何 payload
        ↓ --check 校验漂移
```

- 面数预算：角色 **1500–4500 tris**、场景道具 **300–1500 tris**、远山 **~20 tris**
- **角色必须是单 mesh**（每个角色 1 个 `SkinnedMesh`）——这是 60 人同屏的前提
- **修改骨骼必须改 `scripts/blender/build_rig.py` 并重跑**（`index.html` 里的 `BLENDER_RIG_PY` 是从它同步来的）
- **占位方块只允许出现在布局验证阶段**，进入画质阶段前必须替换成正式资产

## 3. 场景构图与细节密度

- **地面不得肉眼可见平铺**：靠 `groundTex.repeat` 与多尺度噪声（当前 repeat 28）；验收用 P13 的**高通自相关峰值 < 0.15**
- **植被/碎屑微动**：尘粒随风、旗面顶点动画、火盆闪烁——**不允许完全静态**
- **每个物体正确贴地**：禁止悬浮；关楼/营帐/哨塔都有碰撞体与贴地 Y
- **近景资产必须有法线细节 / 边缘磨损 / 环境污渍**：不是干净单色
- **远景用雾 + 大气透视 + 动画 LOD 维持纵深**：距离分档 18/35/60 m，禁止远处物体突现或跳变

## 4. 迭代与验收（强制循环，**不允许一次性生成后结束**）

### 4.1 每轮必须做

1. 跑验收：`python3 scripts/verify.py && python3 scripts/verify_photo.py`
2. **先读测量值，再读结论**——脚本会打印 `fps / draw / tris / tilingPeak / edgeDensity / roiStd / 保持率 / load1`
3. 若某项失败，先判断是**产品问题**还是**环境噪声**：
   - 看 `load1`（>4 时 P10 自动降级为只报告）与**空场基线**
   - 同一构建在 load 2.9 时 60 fps、load 21 时 32 fps —— 这是环境，不是代码
4. 改完**再跑一次**，用**前后对比数字**说话，不接受"看起来好了"

### 4.2 每轮报告格式

```
本轮修复了什么：<机制 + 关键参数>
截图/指标验证了什么：<具体数值，前后对比>
剩余不达标项及原因：<区分"产品"与"环境">
```

### 4.3 帧率不足时的削减顺序

**优先削**：阴影分辨率 → 后处理开销（SSAO 采样 / 体积光）→ 远景细节（尘粒 / 动画频率）→ 分辨率（`quality`）
**最后才动**：材质通道、角色面数、单位上限

## 5. 可编辑性约束（单文件项目特化）

本项目没有场景树，可编辑性靠**代码结构**：

- **14 个编号分节**（`1. 渲染器` … `14. 主循环`），新增内容必须落进对应节
- **具名全局/具名函数**：`sun` / `nearSun` / `atmosphere` / `gradePass` / `fxaaPass` / `player` / `PRESSURE` / `BREAKABLES` / `META`；禁止匿名 IIFE 包裹核心状态
- **不压缩、不混淆**，`demos/index.html` 是可读源码
- **每个机制必须有 `__dbg` 钩子**（如 `__dbg.fx()` / `pressure()` / `roles()` / `objective()`），否则验收测不到
- **常量集中**：`GROUND_R` / `GATE_Z` / `MAX_TOKENS` / `Q_MIN` 等不要散落魔数

## 6. 本项目踩过的坑（禁止重犯）

| 坑 | 症状 | 规则 |
|---|---|---|
| **CSP 哈希锁定** | 改一行内联脚本 → 白屏 | 用 `script-src 'unsafe-inline' 'unsafe-eval'`，**不要重新钉 sha256** |
| **`setInterval` 跑游戏逻辑** | 暂停/慢动作时仍在走 | 一切游戏时间走 `tick(dt)`，用累加器代替 `setInterval` |
| **后台标签页 rAF 被节流** | 测"跳跃/霸体回复"永远是 0 | **确定性测试一律用 `__dbg.step(dt,n)`**，不要靠 `wait_for_timeout` |
| **测试绕过产品入口** | 测"闪避斩"实际测的是 `startAttack` | 必须走真实入口（`__dbg.light()` / `dash()` / `jumpKey()`） |
| **测试脚手架残留状态** | 误判"机制没生效" | 每个用例前显式清 `hurtT / invuln / state / atk` |
| **自适应难度缩放伤害** | 验收的"站桩掉血"变随机数 | **动态难度只调节奏**（刷兵/齐射/技能 CD），不碰伤害数值 |
| **新机制无断言** | "看起来能看"但悄悄坏了 | 每个机制都要有一条**行为断言**或可量化的 A/B 指标 |
| **Bot 时序错误伪装成机制失败** | "进阶打法更差"其实是没跳到空中 | 解读机器人结论前，**先断言机器人真的执行了动作**（记录 `jumps` / `airAtk` 次数） |
| **字段同名污染** | 敌将处刑条被硬直抗性覆盖 | 新状态用独立字段（`stagMax/stagAcc` vs `poise`） |

## 7. 输出要求

交付时列出：

1. **本轮改了什么**（机制 / 参数 / 影响面）
2. **渲染特性清单**（当前启用的 pass 与参数）
3. **资产状态**（面数、骨骼数、贴图通道、体积 KB）
4. **实测数字**（fps / draw / tris / 亮度 / 保持率 / load1，**含前后对比**）
5. **未达标项及原因**（明确区分"产品限制"与"环境限制"）
6. **验收结果**（`18/18` + `14/14`，若未全绿说明哪条、为什么）

> 禁止在无实测数据的情况下声称"已优化"或"已达标"。

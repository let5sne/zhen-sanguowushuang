用 Three.js（从 CDN 引入，只允许这一个库）做一个浏览器里能玩的《真·三国无双》式割草动作游戏，做成单文件 HTML，不许加载任何外部模型、图片、音频文件——所有模型、贴图、音效、UI 全部用代码生成。

**场景**：虎牢关外的平原战场。黄昏、干燥的黄土、远处低矮山脉与雾、一座关楼、若干营帐与战旗、火盆。要有尘土、热感和战场压迫感。

**玩家**：赵云，白甲金边、红缨、白袍、长枪。第三人称越肩视角，鼠标转视角，WASD 移动，Shift 疾跑，空格闪避。

**战斗**：
1. 左键 / J 三段连斩，第三段击倒；右键 / K 蓄力重击（按住蓄力，越久越痛，带冲击波）。
2. 有多少打多少：一次挥击命中扇形范围内所有敌人，要有命中停顿、屏幕震动、伤害数字、火花与击退。
3. 无双槽：命中与受击积攒，满后按 F 进入约 4 秒无双乱舞——无敌、旋转攻击、持续范围伤害、屏幕变色。
4. 锁定（Tab）拉近镜头并自动转向敌将。

**敌人**：刀兵、枪兵、弓兵三种杂兵，各自有追击 / 蓄力 / 出招 / 后摇 / 硬直状态，会占位、包夹、拉开距离放箭；同屏 60 人以上。敌将两名：华雄（先）→ 吕布（后），体型更大、血更厚、伤害更高，有独立血条与出场喊话。

**规则**：击破数统计、连击数与评级（C/B/A/S/无双）、计时；每 25 击破回血；华雄死后吕布带护卫登场；吕布被讨取即胜利，玩家血量归零即失败，结算页显示击破数与用时。

**表现要求**：
- 60fps，同屏 60+ 单位不掉帧；画质随帧率自适应。
- 单位用实例化渲染（InstancedMesh），骨骼用程序化摆位（走路、挥砍、硬直、倒地）。
- 要有：受击闪白、死亡倒地、尘土与血雾粒子、地面冲击环、披风摆动、旗帜飘动、火焰跳动、Bloom、暗角、胶片颗粒。
- 音效全部合成：挥空、命中、兵器交击、重击落地、战鼓配乐、铜锣、无双爆发、弓弦、脚步、人群。必须过压缩器，不许削波。
- UI：顶部章节 / 击破数 / 计时，左上头像与血条、无双槽，右下连击数与评级，敌将血条，中央喊话横幅。

**验收**：控制台零报错；`window.__dbg` 暴露 `st() / info() / lum() / spawn() / killBoss() / musou() / step()`，让自动化脚本能断言状态、读渲染统计与像素亮度。
